# Archived Research: Fluid Collision

Status: Archived
Date: 2026-02-13

This folder contains research and reference material for a GPU Navier-Stokes
fluid simulation (velocity/pressure/diffusion, shader pipelines, render-target
ping-pong) and was used during earlier exploration.

Current foam implementation uses splat-driven particle motion only and no
longer relies on a velocity-field solver. The contents here are kept for
historical reference and are not part of the active approach.
